# ListeningLab - CET-6 英语听力精听训练软件

ListeningLab 是一款面向大学英语六级（CET-6）备考的本地精听训练工具，支持逐句播放、倍速调节、听写纠错、难句收藏与复习、学习进度保存等功能。

## 功能特性

- **材料库**：内置六级听力真题样本，支持导入自有音频与字幕（SRT/LRC/TXT）
- **精听练习**：逐句播放、单句循环、A-B 区间复读、倍速调节（0.5x-2.0x）、原文显隐切换
- **听写纠错**：词级 diff 对比，标记正确/错误/漏写/多写，计算正确率
- **难句复习**：收藏句子统一管理，支持快速播放与重做听写
- **学习进度**：自动保存每套题的当前句、倍速、循环等设置，刷新后恢复
- **键盘快捷键**：空格播放/暂停、方向键切句、Tab 切换原文显隐、Ctrl+Enter 提交听写等

## Windows 双击运行

exe 由 GitHub Actions（`.github/workflows/windows-exe.yml`）在推送到 GitHub 后自动构建，本仓库不预置：在仓库的 Actions 页面选择最新一次 windows-exe 构建，下载 `ListeningLab-windows` 产物即可；打 `v*` 标签时 exe 会同时附到对应 Release。

使用方式：双击 `ListeningLab.exe`，它会自动启动本地服务、选择空闲端口并打开系统默认浏览器；关闭控制台窗口或按 Ctrl+C 即可退出。首次启动稍慢属正常现象：单文件 exe 需先把内置资源（含约 92 MB 音频）解压到临时目录。学习数据保存在用户主目录的 `~/ListeningLabData/` 下，删除 exe 不会丢失进度。

## 从源码运行

要求：Python 3.13（标准库即可，无需额外依赖）

    cd listeninglab
    ./run.sh

指定端口：

    ./run.sh --port 8080

也可执行 `python3 launcher.py`，自动选择空闲端口并打开系统默认浏览器；`./run.sh` 默认监听 8765，启动后访问 http://127.0.0.1:8765 即可。

## 使用流程

1. **选择材料**：在「材料库」选择一套真题，点击「开始精听」或「听写」
2. **精听练习**：左侧句子列表可快速跳转；右侧大字显示原文，支持模糊/隐藏；底部播放器控制倍速与循环
3. **听写检验**：点击「本句听写检验」进入听写模式，输入听到的内容后提交，系统会显示词级 diff 与正确率
4. **收藏难句**：精听或听写时点击星标收藏句子，在「难句复习」中集中复习
5. **查看进度**：「学习进度」页面可查看整体学习统计

## 导入自有音频/字幕

1. 在「材料库」点击右上角「导入本地音频/字幕」
2. 选择音频文件：支持 MP3、WAV、M4A 格式
3. 可选：选择字幕文件：
   - **SRT**：支持标准时间轴格式（`00:00:01,000 --> 00:00:05,000`），系统按时间轴切分逐句播放
   - **LRC**：支持标准歌词时间标签（`[00:01.50]文本`），自动按句切分
   - **TXT**：纯文本换行切句，无预设时间轴
4. 若未提供字幕文件，系统将导入为单段完整音频进行整段播放
5. 导入后的文件保存在 `content/imported/<paper-id>/` 目录下，元数据同步登记至数据库

## 数据文件位置、备份与清空

- **学习数据库**：`data/listeninglab.db`（SQLite 格式，记录每套题的学习进度 `progress`、难句收藏 `bookmarks`、听写评测记录 `dictation_attempts` 及用户偏好 `settings`）
- **内置真题与音频**：`content/papers/`
- **自有导入文件**：`content/imported/`

### 备份数据
直接复制 `data/listeninglab.db` 文件（或整个 `data/` 目录）至安全备份目录即可；恢复时关停服务后覆盖原文件。

### 清空数据
- **界面操作**：在导航栏点击「设置」-> 底部点击「清空所有学习数据并重置」，确认后自动清空数据库并重新初始化。
- **命令行操作**：关停服务后执行 `rm -f data/listeninglab.db`，再次启动服务将自动根据内置真题重新生成全新的数据库。

### 内容真实性与音频性质说明

详细来源与核对记录保存在 [content/SOURCES.md](content/SOURCES.md)：
- **`verified: Yes` 与 `model-reconstructed` 的区别**：
  - `verified: Yes`：表示真题题目、选项及原文已按考场公开权威纸质/网络来源逐字校对核准；
  - `model-reconstructed`：表示试卷内容基于考点框架与场景由大语言模型重构，词汇量与句式严格匹配六级考纲，但并非考场逐字还原。
- **音频性质**：内置音频全部使用本地离线语音合成引擎（Piper TTS，en_US medium 模型，语速约 145–155 wpm，句间 0.35s 停顿，22.05kHz 单声道 32kbps MP3）逐句离线生成，**并非考场原声录音**。

### 音频缺失提示与重新合成

若某些套题音频缺失或需重新生成，系统将在页面与接口中明确给出提示。重新合成需依赖本机环境（Piper 虚拟环境 `~/.local/share/listeninglab-tts/venv` 与语音模型 `~/.local/share/listeninglab-tts/models`），合成命令如下：

```bash
# 重新合成单套真题音频（如 2024-06-1）
python3 content/tts/synthesize.py content/papers/cet6-2024-06-1.json

# 强制重新合成全部 10 套真题音频
python3 content/tts/synthesize.py --force
```

### 内容与音频校验

执行以下命令自动校验所有真题的 Schema、题目选项答案、逐句与整卷音频时长一致性，并更新汇总报告：

```bash
python3 content/validate.py
```

## 项目结构

    app/                  # 后端（Python 3.13 标准库）
    web/                  # 前端（原生 HTML/CSS/JS）
    content/papers/       # 内置真题数据（JSON + 本地合成音频）
    content/tts/          # 本地离线合成流水线（synthesize.py）
    content/validate.py   # 数据与音频校验脚本
    tests/                # 单元测试
    run.sh                # 启动脚本

## 测试

    python3 -m unittest discover -s tests

测试覆盖：词级 diff 打分算法、字幕切句（SRT/LRC/TXT）、进度保存与恢复、API 冒烟测试。

## 已知限制

- 内置音频为本地 TTS 合成音频，建议用于日常逐句精听与听写练习；考前冲刺仍需结合考场原声磨耳朵。
- A-B 区间循环的视觉标记在进度条上显示，当前仅支持单句内微调。
- 导入无字幕音频时，不自动语音转文字切句，需手动提供字幕文件。
- 前端图表（学习进度页折线图/雷达图）为静态演示，动态数据渲染在后续迭代中完善。

## 技术说明

- **零外部依赖**：后端主程序仅使用 Python 3.13 标准库（http.server、sqlite3）；前端无框架、无 CDN、无构建步骤
- **断网可运行**：音频随代码提交，所有资源本地加载，完全离线可用
- **单用户本地应用**：当前为单机版，数据保存在本地 SQLite（data/listeninglab.db）
